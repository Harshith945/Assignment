# Most Complex Python Code

## Project: AI Research Agent

This is one of my most complex Python/GenAI projects.

The system takes a research topic and uses a LangGraph workflow to:
1. Plan research questions
2. Search the web
3. Summarize collected information
4. Evaluate whether the research is sufficient
5. Loop back for additional research when necessary

### Technologies

- Python
- LangGraph
- LangChain
- Groq LLM
- DuckDuckGo search
- Pydantic structured output
- Streamlit

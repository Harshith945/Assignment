# Most Complex Database Code

## Project: Resume ATS Assistant

The recruiter mode of the Resume ATS Assistant uses semantic matching
between resumes and job descriptions.

Resume content and job requirements are converted into embeddings and
stored/searched using Pinecone so that semantically relevant resumes can
be retrieved for a job description.

### Technologies

- Python
- Embeddings
- Pinecone
- Semantic search
- LLM / GenAI
